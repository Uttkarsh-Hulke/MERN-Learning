# Task 4 - CSS Units, Box Model, Fonts

## Description
This project demonstrates the use of CSS units, the box model, fonts, gradients, and responsive design using viewport units.

## Features
- Responsive container using vw and vh
- Image displayed inside a container

- CSS Box Model

- External stylesheet
