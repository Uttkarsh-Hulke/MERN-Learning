# Laundry Mart Login Page

This is my CSS Flexbox assignment. I made a simple login page for a laundry service.

## What I added
- Two sections using Flexbox
- Laundry image on the left side
- Laundry Mart name and short text
- Email and password fields
- Forgot Password link
- Login button
- Register Now link
- Button hover effect
## Technologies
- HTML
- CSS
- Flexbox
## Files
- index.html
- style.css
- Laundry.webp
- Readme.md
## How to run
Open the `index.html` file in a browser.
## CSS used
I used basic CSS properties like width, height, padding, colors, margin and Flexbox to arrange the page.

The main container uses `100vh` so the page takes the full screen height.
