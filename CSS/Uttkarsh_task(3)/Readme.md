# CSS Assignment 3

This is a basic CSS assignment for practicing different types of CSS selectors.

## Topics Used

- Element selector
- Class selector
- ID selector
- Descendant selector
- nth-child selector
- Background and text colors
- Font size

## Files

- index.html - contains the HTML structure
- style.css - contains all the CSS styling

## What I Learned

In this assignment I learned how to select HTML elements in different ways using CSS. I also practiced how class, id and element selectors work and how nth-child can be used to style specific elements without giving them a class or id.

## Output

The webpage contains headings, paragraphs, links and lists styled using external CSS.
