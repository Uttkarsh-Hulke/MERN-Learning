# Laundry Services Hero Section

This is a simple laundry service website created using HTML and CSS.

## Features

- Navigation bar
- Logo
- Home, Services, About Us and Contact Us links
- Username section
- Hero section
- Laundry service heading
- Description
- Book a service button
- Laundry image
- Hover effects

## Technologies Used

- HTML
- CSS

## Files

- index.html
- style.css
- laundry.png

## How to Run

Open the `index.html` file in a web browser.

## Purpose

This project is created to practice HTML and CSS concepts such as inline-block, position, padding, margin, vertical-align and basic styling.
