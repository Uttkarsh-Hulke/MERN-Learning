
# JavaScript Array Operations

## About

A basic JavaScript project created to practice arrays, functions, loops, conditions, and `forEach()`.

## Features

* Find the maximum value in an array
* Calculate the sum of array elements
* Count odd numbers
* Iterate through an array using `forEach()`
* Display results in the browser console

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
javascript-array-operations/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Open `index.html` in a web browser.
2. Open Developer Tools using `F12`.
3. Go to the **Console** tab.
4. View the array elements and calculated results.
