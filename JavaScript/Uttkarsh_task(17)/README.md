## task 14

This is a simple JavaScript project using Promises.
## What it does
 Divides two numbers.
Uses `resolve()` when the division is successful.
Uses `reject()` when the second number is `0`.
Uses `.then()` for the result and `.catch()` for errors.


## for Example

`10 / 2` gives `5`.
but
`10 / 0` gives an error because division by zero is not allowed.
