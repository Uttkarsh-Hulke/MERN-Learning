# Compound Interest Calculation
This is my JavaScript task for calculating compound interest.
## What I used
- HTML
- CSS
- JavaScript
## What the program does

The program takes some basic values like:

- Principal amount
- Interest rate
- Compounding frequency
- Time period
It then calculates the final amount and compound interest using the compound interest formula.
